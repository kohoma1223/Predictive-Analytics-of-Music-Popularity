# Predictive-Analytics-of-Music-Popularity
## Overview
This project analyzes over 100,000 Spotify tracks to identify which audio features are most predictive of song popularity.

## Objective
To build predictive models that classify song popularity based on audio characteristics and explore patterns within the data.

## Dataset
- Public Spotify dataset containing over 100,000 tracks
- Features include danceability, energy, tempo, valence, acousticness, and more

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Methods
- Data cleaning and preprocessing
- Regression analysis
- Classification modeling
- K-means clustering

## Results
- Achieved 77% classification accuracy
- Evaluated performance using R², precision, recall, and confusion matrices
- Identified distinct song clusters based on audio characteristics

## Skills Demonstrated
- Data analysis
- Machine learning
- Model evaluation
- Data visualization
